# Automação de Tarefas com Python (Projeto Hashtag)

Este projeto foi desenvolvido com base nas aulas de automação da Hashtag Treinamentos. O objetivo foi criar um script inteligente em Python para automatizar processos repetitivos de manipulação de dados, aplicando conceitos de lógica que venho estudando na graduação de Ciência da Computação.

## Tecnologias e Ferramentas Utilizadas
- Linguagem: Python
- Biblioteca Principal: Pandas (para manipulação e análise de dados)
- Gerenciador de Pacotes: PIP
- Armazenamento de Dados: Arquivos CSV (utilizados como base de dados para leitura/escrita do bot)

## O que este Bot faz / O que eu aprendi:
- Leitura automática de bases de dados em formato de planilha (CSV).
- Tratamento e filtragem de dados em massa utilizando o Pandas.
- Automatização de tarefas manuais que poupam tempo operacional.
- Organização de scripts limpos e execução direta via terminal (sem necessidade de interface visual/front-end).

## Como rodar o projeto na sua máquina:
1. Instale o Python no seu computador.
2. Instale a biblioteca Pandas executando no terminal: pip install pandas.
3. Execute o arquivo principal do script.
